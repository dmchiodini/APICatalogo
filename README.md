# 🛒 APICatalogo (.NET 8 & Entity Framework Core)

> Web API corporativa desenvolvida em **.NET 8** utilizando **Entity Framework Core (ORM)**, banco de dados **MySQL** e documentação interativa com **Swagger / OpenAPI**.

![Swagger Documentation](https://github.com/dmchiodini/APICatalogo/assets/41700939/a78c0264-ae08-49be-b034-c7b5d76287df)

---

## 🚀 Tecnologias e Práticas

- **C# & .NET 8**
- **Entity Framework Core (Code-First / Migrations)**
- **MySQL Database**
- **Repository Pattern / DTOs**
- **Swagger / OpenAPI** para teste e documentação viva dos endpoints
- **Data Annotations & Validação de Entrada**

---

## 📦 Como Executar

```bash
# Clonar o projeto
git clone https://github.com/dmchiodini/APICatalogo.git

# Restaurar dependências
dotnet restore

# Executar a aplicação
dotnet run
```
